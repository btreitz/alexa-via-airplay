Alexa via AirPlay

1 Public URL

The HTTPS address that reaches this bridge's public port (8099). Echos fetch the stream from here.

Check only after the DNS record or tunnel hostname exists: a lookup before that gets "not found" cached for up to 30 minutes.

3 Alexa skill

Your own private skill tells the Echo where to fetch the stream. Create it once in the Alexa developer console, signed in with the Amazon account that owns your Echos.

  1. Create Skill: any name; primary locale = your Echos' language; experience Other; model Custom; hosting Alexa-hosted (Node.js); template Start from Scratch.
  2. Build → Interaction Model → JSON Editor: replace everything with the interaction model below, Save.
  3. Build → Interfaces: enable Audio Player, Save, then Build skill.
  4. Code → lambda/index.js: replace everything with the skill code below, Save, Deploy.
  5. Test: set skill testing to Development. The simulator doesn't play audio; test on a real Echo.

4 Echos

Switch on the Echos that should appear as AirPlay receivers. Press Test once per Echo so the bridge learns which one is which.

Settings

Turn the IP check off only if your Echos reach the internet through a different IP (VPN, second uplink). Behind CGNAT it protects less, see the setup guide.
